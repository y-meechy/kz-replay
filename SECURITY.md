# Security policy

## Supported versions

This project is pre-1.0. Security fixes are made on the current default branch;
older commits and deployments are not supported separately.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
**Security** tab and choose **Report a vulnerability** to send a private security
advisory to the maintainers. Include:

- the affected commit or deployed URL;
- the impact and prerequisites;
- reproducible steps or a minimal proof of concept; and
- any suggested mitigation, if known.

Do not access data that is not yours, degrade a public service, or test against
third-party CS2KZ, Steam, Valve, or Workshop infrastructure without permission.
Use a local instance wherever possible.

The maintainers will acknowledge a complete report when available, investigate it,
and coordinate a fix and disclosure. No response time or bounty is promised. If the
GitHub private-reporting option is unavailable, open a public issue containing no
sensitive details and ask for a private contact channel.
