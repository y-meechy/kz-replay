Linking to a replay

/watch?ids=<record id>
/watch?ids=<first>,<second>

The first id is the run you watch. The second is the one it gets measured against. Swap them to watch the other side.

Two is the limit. Extra ids get dropped and the viewer says so on screen.

Both runs have to be the same map, the same course and the same mode. If they are not, the viewer loads the first one on its own and tells you why.

The world record feed

/wr
/wr?id=<record id>

The newest world records in the game, one screen each, scrolled like a phone feed. The record on screen is always in the address bar, so a link opens on the run you were looking at.

Every run plays through the runner's eyes and loops. The feed has no controls on purpose: ↑ ↓ move between records and enter opens the one on screen in the full player, where the cameras, the timeline and the comparison live.

Camera

/watch?ids=<record id>&view=pov
pov Through the runner's eyes. This is the default.
follow Behind the runner.
free Fly anywhere. Drag to look, WASD to move, Q/E for down and up, hold Shift to go fast. orbit still works in old links.

Leave view off and you get pov.

Map geometry powered by Source 2 Viewer (ValveResourceFormat). The Source 2 file formats are not documented by Valve; everything this project knows about them comes from that project's reverse engineering.
